# 阅读界面改版验证

目标：让论文成为主界面，保留现有功能。分三轮独立验证、提交和推送。

1. 阅读正文与共享辅助面板。左侧保留会话、论文和上传入口，右侧在讨论、搜索、文件、任务之间切换，支持固定；不因后台事件强制展开。实际浏览器检查切换后草稿和搜索输入保留；9 项前端测试及构建通过。
2. 阅读与讨论交互。论文、单篇/跨篇、历史导读切换，章节跳转，桌面阅读位置保留；历史讨论和底部输入区分离，八种快捷提问全部保留。追问带当前论文 ID，失败保留草稿。数学公式本地按需加载；实际核对上下标、分式和章节跳转。12 项前端测试、类型检查、构建通过。
3. 统一视觉与中文入口。清理旧卡片、阴影和响应式布局规则，增加窄屏论文导航折叠，保留全部检索历史入口，错误就地显示。补测创建会话、阅读背景与目标、批量上传、搜索保存及归档。

## 功能对应

| 功能 | 改版后的入口 |
| --- | --- |
| 创建/切换会话，分类、阅读背景和目标 | 所有会话、阅读背景与目标 |
| 批量上传与论文列表 | 左侧论文导航、添加论文 |
| 导读关注问题与生成 | 正文顶部 |
| 单篇、跨篇及历史导读 | 正文视图切换与版本选择 |
| 全部分析章节 | 连续正文、章节目录 |
| 追问、八种快捷提问、历史问答及检查信息 | 讨论面板 |
| 文献发现、模式/学科筛选、检索历史、保存与外部链接 | 找论文面板 |
| 原文、解析、分析、参考文献、记忆、任务和归档文件 | 文件面板 |
| 前台运行事件、后台进度/日志/输出、停止任务 | 任务面板 |
| 归档操作与结果路径 | 顶部归档、正文末尾 |

## 实际界面检查

本地前端连接 `.tmp-tests/ui-preview/sessions` 中的隔离后端；内容使用前一轮真实 DPO/IPO 模型输出，未写入正式会话，也未以演示内容替换产品数据源。浏览器验证桌面 1440×960 下并排阅读/讨论，以及 390px 设置下的窄屏布局（实际内容区约 375px）；窄屏无整页横向溢出，输入框与发送按钮可见。最终截图保留在 `.tmp-tests/ui-preview/reading-workspace.jpg`。

最终验证：14 项前端测试、47 项后端测试、TypeScript 类型检查和生产构建全部通过。主要脚本 gzip 约 57.45 kB，公式脚本独立 gzip 约 78.06 kB；工具面板和 Markdown 排版未引入整套 UI 框架。

公式渲染为独立代码块按需加载，不依赖 CDN；它增加了公式页面所需资源，不声称整站加载速度已经提高。原有 Markdown 渲染器仍是有限子集，不支持全部 Markdown 扩展。跨篇比较仅在已有相应分析时可选，没有删除未生成内容，也不伪造比较。
